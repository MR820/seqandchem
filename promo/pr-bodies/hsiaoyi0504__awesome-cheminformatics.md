Adds [SeqChem](https://seqandchem.com/api), a free JSON API over OpenBabel covering format
conversion (190+ formats), molecular descriptors, 2D depiction, 3D conformer generation, SMARTS
substructure search and Tanimoto similarity.

No API key is required, and there is an OpenAPI 3.0 spec at
https://seqandchem.com/api/openapi.json.
