What this SMILES to SDF converter does

This converter turns a SMILES string into an SDF structure file. SDF is what most molecular viewers, docking programs and modelling pipelines accept. When the 3D coordinates option is enabled, OpenBabel generates an initial geometry and optimises it with a force field so the file contains a real 3D conformer rather than a flat drawing.

Paste one SMILES or a list, one per line. The output contains one SDF record per molecule, separated by $$$$. To go the other way, use SDF to SMILES; for a single MOL file, use SMILES to MOL.

What you get

  • A valid V2000 SDF block with atom and bond tables.
  • 2D layout by default, 3D conformer when 3D coordinates is checked.
  • Explicit hydrogens when 3D coordinates are generated.
  • One record per input molecule, in the same order.

2D vs 3D

OptionWhat it doesUse when
2D (default)Generates a flat, readable layoutEditing, reports, database storage
3D coordinatesBuilds and optimises a conformerDocking, molecular dynamics, 3D viewers

3D generation takes longer and produces one low-energy conformer, not an ensemble. For a flexible molecule, the result depends on the starting geometry and the force field. Use a dedicated conformer generator if you need to sample multiple minima.

What is preserved

  • Connectivity and bond orders — from the SMILES.
  • Formal charges — written into the atom block.
  • Stereochemistry — wedge/hash bonds and stereo flags when the SMILES defines it.
  • Coordinates — 2D layout or 3D conformer, depending on the option.

SMILES does not carry properties or names, so the SDF record has a structure block and no metadata. Add data fields in your downstream tool if you need them.

Salts and multiple components

A SMILES with a salt or mixture contains disconnected components separated by dots. The SDF record may contain all components in one record or split them depending on the input. Check the record and remove counter-ions first if you want the parent compound only.

Common uses

  • Preparing a ligand for docking or a 3D viewer (SMILES to PDBQT for AutoDock).
  • Building a compound library from a SMILES list (batch converter).
  • Opening a SMILES structure in ChemDraw, Marvin or Avogadro.
  • Generating a starting geometry for a quantum-chemistry calculation (SMILES to XYZ).

Frequently asked questions

Is the 3D conformer the global minimum?

No. OpenBabel performs a fast force-field optimisation (MMFF94 or UFF) from a generated starting geometry. It produces a low-energy conformer, not a guaranteed global minimum, and only one conformer — not an ensemble.

Can I convert many SMILES at once?

Yes. Put one SMILES per line and the output will contain one SDF record per molecule, separated by $$$$.

Does it add hydrogens?

3D generation adds hydrogens because a 3D geometry needs them. For a 2D SDF, hydrogens are implicit unless you use the add-hydrogens option.

Does it preserve stereochemistry?

Yes, when the SMILES defines it. Chiral centres and double-bond geometry are written into the atom and bond blocks.

Why does the SDF record have no properties?

SMILES has no property data. The SDF record contains the structure only; add data fields in your downstream tool if you need names, IDs or assay values.

Can I convert the SDF back to SMILES?

Yes — use SDF to SMILES. The round trip preserves connectivity and defined stereochemistry, but not the 3D coordinates in the SMILES output.
