DNA to protein translation

Ribosomes read nucleotides in triplets called codons, each coding for one amino acid. With four possible bases there are 64 codons encoding 20 amino acids plus three stop codons (TAA, TAG, TGA), which are shown as * in the output.

Reading frames

A sequence has three forward reading frames, depending on whether translation starts at the first, second or third base. Choosing a frame changes the protein completely, so try all three when the correct frame is unknown.

Codon usage is not considered

Translation uses the standard genetic code. Mitochondrial codes, where TGA can encode tryptophan, are not applied.

Frequently asked questions

What does X mean in the output?

X marks a codon containing an ambiguous base (such as N) that cannot be resolved to a single amino acid.

Does it handle RNA?

Yes — U is treated as T.
