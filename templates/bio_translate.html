What this DNA to protein converter does

Paste a DNA or RNA sequence and translate it into amino acids using the standard genetic code. The tool reports all three forward reading frames, preserves FASTA headers for multi-record input and marks stop codons as *. It translates the sequence from the first base of the selected frame — it does not search for the first ATG or predict open reading frames.

For the opposite strand, use the reverse complement tool first, then translate the result. For sequence composition, use the GC content calculator.

How translation works

Ribosomes read nucleotides in triplets called codons. With four possible bases there are 64 codons: 61 encode the 20 standard amino acids and three are stop codons (TAA, TAG and TGA). Translation starts at a start codon — usually ATG, which also encodes methionine — and ends at a stop codon. The protein sequence is written from the N-terminus to the C-terminus, which corresponds to reading the mRNA in the 5′→3′ direction.

This page applies the standard genetic code. Mitochondrial codes and other alternative codes are not applied; in vertebrate mitochondria, for example, TGA encodes tryptophan rather than a stop.

How to read a codon chart

Take the first three bases of the sequence in the chosen frame. Read the first base, then the second, then the third, and find the corresponding row in the chart. For example:

  • ATG → methionine (M), and it is also the usual start codon.
  • GCT → alanine (A).
  • TAA → stop (*), which terminates translation.

The chart is not a lookup by amino acid name alone: several amino acids are encoded by multiple codons (leucine and serine have six each), and the same amino acid can appear in different rows of a codon wheel. Use the full triplet, not just the first two bases.

Reading frames

A sequence has three forward reading frames, depending on whether translation starts at the first, second or third base. Choosing a frame changes the protein completely, so try all three when the correct frame is unknown. The reverse strand adds three more frames; reverse complement the sequence first and then translate.

This tool translates from the beginning of the selected frame. It does not search for an open reading frame (ORF), and it does not trim the sequence to the first ATG. If you need ORF prediction, use a dedicated annotation tool and then paste the ORF here.

Codon usage is not considered

Translation uses the standard genetic code and treats every codon equally. Codon usage bias, tRNA abundance and wobble pairing affect translation efficiency in a cell, but they do not change the amino acid sequence, so they are not part of this calculation.

Frequently asked questions

What does X mean in the output?

X marks a codon containing an ambiguous base (such as N) that cannot be resolved to a single amino acid. Replace the ambiguous base with a concrete base if you know it.

Does it handle RNA?

Yes — U is treated as T. The output is the same protein sequence; the only difference is the alphabet of the input.

Does it find the start codon automatically?

No. The tool translates the whole sequence in the selected frame. To translate an ORF, paste the ORF starting at its ATG, or trim the sequence first.

Can I translate multiple sequences?

Yes. Paste a multi-record FASTA file; each record is translated independently and the headers are preserved. For large files, use the API with the translate operation.

Does it apply mitochondrial or alternative genetic codes?

No. The standard genetic code is used for every sequence. Alternative codes, such as the vertebrate mitochondrial code where TGA encodes tryptophan, are not applied.

Why does the protein end with an asterisk?

The asterisk marks a stop codon. If the sequence continues past it, the downstream codons are still translated because the tool processes the whole input; trim the sequence at the stop codon if you want the mature protein only.
