Tanimoto Similarity Calculator

Compare two molecules and get their Tanimoto similarity using FP2, FP3, FP4 or MACCS fingerprints. A score of 1.0 means identical fingerprints; 0.0 means no overlap.

What Tanimoto similarity measures

Each molecule is converted into a binary fingerprint — a bit string where each bit means “this substructure or path is present”. The Tanimoto coefficient compares two fingerprints by dividing the number of shared bits by the number of bits present in either molecule:

T(A, B) = |A ∩ B| / |A ∪ B|

The result is between 0 and 1. A value of 1.0 means the fingerprints are identical; 0.0 means they share no bits. Because the comparison is done on fingerprints rather than on the full graph, the score is fast enough for screening large libraries.

How to read the score

TanimotoTypical interpretation
1.0Identical fingerprint — usually the same canonical structure
0.85–1.0Very similar; often the same compound or a close analogue
0.5–0.85Similar scaffold or related series
0.3–0.5Some structural overlap; may share a functional group
< 0.3Little structural overlap

These thresholds are rules of thumb, not a definition. The “same compound” cutoff depends on the fingerprint, the molecule size and the task; a score of 0.85 with MACCS is not the same evidence as 0.85 with FP2. Always report which fingerprint produced the number.

Which fingerprint should I use?

FingerprintTypeGood for
FP2Path-based, 1024 bitsGeneral-purpose similarity and virtual screening
FP3Path-based, smallerFaster, more permissive comparisons

MACCS166 structural keysInterpretable, key-based matching

For a first pass, FP2 is a sensible default. Use MACCS when you need to explain which substructures drove the similarity, and FP4 when functional groups matter more than the carbon skeleton.

Worked example

The default pair is aspirin (CC(=O)Oc1ccccc1C(=O)O) and its methyl ester (CC(=O)Oc1ccccc1C(=O)OC). They share the aromatic ring, the acetate group and most of the skeleton; they differ at the carboxylic acid. The Tanimoto score is therefore high — typically above 0.8 with FP2 — but not 1.0, because the acid and ester produce different fingerprint bits.

This is the intended use of the score: it tells you that two structures are closely related, not that they are interchangeable. Check the structures before treating them as duplicates.

Limitations

  • 2D fingerprints ignore 3D shape. Two molecules with the same connectivity but different conformations can score 1.0.
  • Protonation and charge can change the fingerprint. Compare molecules in the same protonation state.
  • Salts and counter-ions add bits. Strip them first if you want to compare the parent compound.
  • Different fingerprints give different scores. A pair can be highly similar with FP2 and less similar with MACCS.
  • Similarity is not bioactivity. A high Tanimoto score does not guarantee that two compounds share a target or an effect.

Common uses

  • Virtual screening: rank a library against a query compound.
  • Duplicate detection: flag near-identical records before registration.
  • Clustering: group analogues by fingerprint similarity.
  • Scaffold hopping: find molecules with similar substructures but different frameworks.

For substructure matching rather than similarity, use the SMARTS substructure search. For molecular properties, use the property calculator. For bulk comparisons, the API and batch tools accept multiple structures.

Frequently asked questions

What is a good Tanimoto score?

There is no universal cutoff. In many virtual-screening workflows, 0.7–0.8 is used as a “similar” threshold and 0.85+ as a “very similar” threshold. The right cutoff depends on the fingerprint and the diversity of your library.

What is the difference between Tanimoto and cosine similarity?

Both compare binary fingerprints. Tanimoto divides the intersection by the union; cosine divides the intersection by the geometric mean of the set sizes. They are related but not identical, and the ranking of a library can differ.

Which fingerprint is best?

FP2 is a good general default. MACCS is more interpretable, FP4 emphasises functional groups and FP3 is faster. Try more than one fingerprint when the decision is important.

Can I compare more than two molecules?

This page compares a pair. For a library, use the API or a script that computes the fingerprint matrix once and then compares all pairs.

Does the score consider 3D conformation?

No. The fingerprints are derived from the 2D connection table. Use a 3D shape-similarity tool if conformation matters.

Why do I get different scores with different fingerprints?

Each fingerprint encodes different structural features. FP2 uses paths, FP4 uses SMARTS patterns and MACCS uses predefined keys, so the same pair can produce different numbers.
