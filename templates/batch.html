Why batch conversion?

  
Most chemistry work happens on libraries, not single molecules. This tool runs OpenBabel
     over every record in your file in one pass, so a 1000-compound SDF becomes a clean SMILES
     list in seconds instead of 1000 manual conversions.

Frequently asked questions

  
How large can the file be?

  
Up to 64 MB of text and 5,000 records per run — or
     500 records when the output is an image, since each one is rendered in a
     separate pass. 3D generation is limited to 200 records per run because
     coordinates are optimised for every molecule. Exceeding a limit returns an error before
     conversion starts, telling you how many records you sent and what the maximum is.

  
Can I preview 3D results?

  
Yes. Select a 3D output format (SDF, MOL, MOL2, PDB, XYZ, CML) and the page shows an
     interactive 3D preview of the first few molecules. Use the molecule selector to browse
     the preview; the download always contains the full batch.

  
What if some records fail?

  
OpenBabel skips records it cannot parse and reports how many were converted. The output
     keeps the successful ones in their original order.

  
Can I convert to different formats per record?

  
No — one run produces one output format. Run the tool again with a different target format
     if you need several.
