Why batch conversion?

  
Most chemistry work happens on libraries, not single molecules. This tool runs OpenBabel
     over every record in your file in one pass, so a 1000-compound SDF becomes a clean SMILES
     list in seconds instead of 1000 manual conversions.

Frequently asked questions

  
How large can the file be?

  
Up to 64 MB of text — roughly 150,000–400,000 SDF records depending on molecule size.
     There is no cap on the number of records, and conversion runs with a 25-minute
     server-side timeout.

  
What if some records fail?

  
OpenBabel skips records it cannot parse and reports how many were converted. The output
     keeps the successful ones in their original order.

  
Can I convert to different formats per record?

  
No — one run produces one output format. Run the tool again with a different target format
     if you need several.
