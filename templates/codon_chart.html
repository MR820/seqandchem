Codon Chart

A complete codon chart for the standard genetic code — all 64 codons, the amino acid they encode, one-letter and three-letter codes, and the start and stop signals. Printable and free to use as a reference.

How to read a codon chart

A codon is a triplet of nucleotide bases read in the 5′→3′ direction. Take the first three bases of your sequence in the chosen reading frame and find the triplet in the chart. For example, ATG encodes methionine (M) and is the usual start codon; GCT encodes alanine (A); TAA is a stop codon.

In the standard code, ATG also encodes methionine, so the first methionine of a protein is usually the start codon. Alternative start codons (GTG, TTG) are used by some bacteria, but they are not treated specially by a standard translation tool.

Why there are 64 codons but only 20 amino acids

Four bases in three positions give 4³ = 64 possible codons. Sixty-one encode amino acids and three are stop signals. The code is degenerate: most amino acids are encoded by several codons, which is why leucine and serine each have six. Degeneracy makes the code robust to some point mutations, because a change in the third base often leaves the amino acid unchanged.

Codon chart vs codon wheel

A codon wheel arranges the same information as concentric circles: the first base is the inner ring, the second base the middle ring and the third base the outer ring. It is popular in teaching because it is compact. A table is easier to search and to read on a screen; both contain the same 64 codons.

Is the genetic code universal?

The standard code is used by the vast majority of organisms, but there are exceptions. Vertebrate mitochondria, for example, read TGA as tryptophan rather than stop, and some ciliates reassign stop codons. This chart shows the standard code; check the organism-specific code if you are working with mitochondrial or non-standard genomes.

Frequently asked questions

How many codons are there?

There are 64 codons: 61 encode the 20 standard amino acids and 3 are stop codons (TAA, TAG and TGA in DNA; UAA, UAG and UGA in RNA).

Which codon is the start codon?

ATG (AUG in RNA) is the standard start codon and also encodes methionine. Some bacteria use alternative start codons such as GTG or TTG, but the standard chart treats ATG as the start.

What are the stop codons?

TAA, TAG and TGA in DNA; UAA, UAG and UGA in RNA. They terminate translation and are marked with an asterisk in protein output.

Why does the chart show T instead of U?

The chart uses DNA codons because DNA sequences are the usual input. For RNA, replace every T with U; the amino acid assignment is unchanged.

Is the genetic code the same in mitochondria?

No. Mitochondrial codes differ in a few codons — most notably TGA, which encodes tryptophan in vertebrate mitochondria instead of acting as a stop. This chart shows the standard code.

Can I print this codon chart?

Yes. Use your browser's print function (Ctrl+P or Cmd+P). The table is plain HTML and prints without scripts or images.
