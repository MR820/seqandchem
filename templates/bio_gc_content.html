What is GC content?

GC content is the percentage of guanine and cytosine bases in a DNA or RNA sequence. Because G–C pairs share three hydrogen bonds while A–T pairs share two, GC-rich DNA is more thermally stable. GC content is used to estimate melting temperature, predict PCR success, compare genomes and check sequencing data for bias.

GC content formula

The calculator uses the straightforward definition:

GC% = (G + C) / (A + T + G + C + other bases) × 100

Every base in the record counts toward the denominator, including ambiguous codes such as N. That means a sequence with many N bases will have a lower reported GC percentage than the same sequence with the Ns removed. If you need the GC percentage of the known bases only, remove the ambiguous positions first.

Example: the 39-base sequence ATGGCCATTGTAATGGGCCGCTGAAAGGGTGCCCGATAG contains 22 G/C bases, so its GC content is 22 ÷ 39 × 100 = 56.4%.

How to interpret GC content

GC contentTypical descriptionContext
< 40%AT-richCommon in some genomes and regulatory regions; lower melting temperature
40–60%ModerateTypical range for many coding sequences and PCR primers
> 60%GC-richHigher melting temperature; can form secondary structures that interfere with PCR

These ranges are rough. A whole genome, a gene, a promoter and a primer each have their own expected GC content; compare a sequence with others from the same context rather than with a universal target.

GC content for PCR primers

For a typical PCR primer, a GC content of 40–60% is a common starting point. Primers that are too AT-rich tend to have low melting temperatures and weak binding; primers that are too GC-rich can form stable secondary structures or misprime. Also check the 3′ end: a run of G/C bases at the 3′ end can increase non-specific extension. The reverse complement tool is useful for checking the reverse primer once the forward sequence is chosen, and the primer Tm calculator estimates melting temperature from the sequence.

Other metrics reported

  • Length — number of bases in the record.
  • AT content — the complementary percentage (A + T + U).
  • N count — ambiguous bases, usually assembly gaps.
  • GC skew — (G − C) / (G + C), used to locate origins of replication and strand asymmetries.
  • AT skew — (A − T) / (A + T), the same idea for the other pair.

GC skew is a ratio, not a percentage: a value near 0 means G and C are balanced, a positive value means G is more frequent, and a negative value means C is more frequent.

Common uses

  • Characterising a genome or a genomic region.
  • Designing and checking PCR primers.
  • Detecting GC bias in sequencing data.
  • Comparing codon usage or nucleotide composition between organisms.
  • Estimating the melting behaviour of a duplex before running an experiment.

Frequently asked questions

Does it handle RNA?

Yes. U is counted the same way as T for the AT statistic, so an RNA sequence is processed without conversion. The GC calculation itself is unchanged.

Can I analyse a whole genome?

Yes, as long as the pasted text stays under the input limit. For multi-FASTA files, each record is reported separately, which is useful for comparing contigs or chromosomes.

What is a good GC content?

There is no universal answer. For PCR primers, 40–60% is a common range; for a whole genome, the expected value depends on the organism. Compare your sequence with the appropriate reference set rather than applying one cutoff everywhere.

Why is GC-rich DNA more stable?

G–C pairs form three hydrogen bonds, while A–T pairs form two. More hydrogen bonds mean more energy is needed to separate the strands, so GC-rich duplexes generally have higher melting temperatures.

What is GC skew?

GC skew is (G − C) / (G + C). It highlights strand asymmetry: a positive value means G is more frequent than C on the analysed strand, a negative value means C is more frequent. In bacterial genomes, skew changes are often used to locate the origin and terminus of replication.

Are ambiguous bases included?

Yes. N and other ambiguous codes count toward the sequence length in the denominator, so they lower the reported GC percentage. Remove them first if you want GC content over known bases only.
