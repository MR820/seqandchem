About SeqChem

SeqChem is a free, account-free collection of chemistry and bioinformatics tools: format conversion, molecular properties, structure depiction, 3D conformers, sequence utilities, codon charts and molecular weight calculators.

What this site is

SeqChem is built for people who need a quick, reliable answer without installing a cheminformatics stack: convert a SMILES to MOL, check a molecule against Lipinski's rules, draw a structure, translate a DNA sequence, calculate a protein mass or look up a codon. Every tool runs on the server, requires no account and keeps no history of the molecules or sequences you submit.

The site also exposes a public JSON API for the same operations. The API is keyless, has fair-use rate limits and is documented at /api; a Python client is available on PyPI.

How the tools work

  • Molecule processing — OpenBabel 3.1.1 handles format conversion, descriptors, depiction and 3D conformer generation.
  • IUPAC names — OPSIN, the Open Parser for Systematic IUPAC Nomenclature from the University of Cambridge, parses systematic names. Common and trivial names fall back to a PubChem lookup from your browser.
  • Sequence tools — FASTA/FASTQ parsing, GC content, reverse complement, translation, molecular weight and primer Tm are implemented in pure Python on the server. The calculations do not call an external service.
  • Web server — Flask behind nginx, with Cloudflare as the CDN.

Accuracy and limits

Chemistry software is a model of reality, not reality itself. A PDB file may not carry bond orders; a SMILES string may be ambiguous about stereochemistry; a predicted logP or Tm depends on the method; a force-field conformer is a low-energy geometry, not an experimental structure. The tools report what the underlying software computes, and the pages explain the assumptions and common failure modes.

SeqChem is a research and educational tool. It is not a substitute for experimental validation, a regulatory submission, a clinical decision or a validated manufacturing process. Check important results against the primary literature or an experimental measurement.

Data and privacy

Molecules and sequences are processed in a subprocess or in Python and are not stored. The anonymous feedback form stores only the message, category, page path and timestamp. Page analytics use Cloudflare Web Analytics, which is cookie-free and does not build a personal profile. Server logs are kept for security and operations. The full policy is at /privacy.

Updates and corrections

Pages are updated when the underlying software changes, when a calculation is corrected or when a user reports a problem. Guides and calculator pages carry a “last updated” date where it matters. If you find an error, the fastest way to report it is the anonymous feedback form — include the page and the input that produced the result. You can also open an issue in the GitHub issue tracker.

Who maintains it

SeqChem is maintained by the SeqChem contributors. The source code is on GitHub; the public API and the Python client are documented separately. There is no advertising, no account system and no paid tier.

The How the tools work section above gives the implementation details; the Accuracy and limits section explains the assumptions that matter when interpreting a result.

Contact

Questions, bug reports and suggestions can be sent through the anonymous feedback form or the GitHub issue tracker. For API or integration questions, include the endpoint and a minimal example input so the issue can be reproduced.
