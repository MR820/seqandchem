3D Molecular Structure Generator

Generate a 3D conformer from a SMILES string or any supported structure format, rotate it interactively in your browser and download the result as an SDF file. Free, no registration and no plugin.

What this 3D molecular structure generator does

Paste a SMILES string, InChI, MOL, SDF, PDB, XYZ, MOL2 or CML structure and the tool builds a three-dimensional conformer. The result is displayed in an interactive viewer — drag to rotate, scroll to zoom — and can be downloaded as an SDF file with explicit 3D coordinates.

The same input can be viewed as a flat 2D drawing with the 2D structure generator. Use 2D when you need a clean figure for a report; use 3D when geometry, conformation or coordinates matter.

How the 3D coordinates are generated

OpenBabel first builds an initial geometry from the connection table, then optimises it with a force field (MMFF94 where parameters are available, UFF otherwise). The optimisation moves atoms to reduce strain and produces a low-energy conformer. Hydrogen atoms are added automatically because a 3D geometry needs them.

This is a force-field conformer, not an experimental structure and not a quantum-mechanical calculation. It is a good starting point for visualisation, docking preparation and teaching, but it is not a substitute for a crystal structure or a high-level conformer search.

What to check before using the conformer

  • Protonation and charge — draw the molecule in the protonation state you care about. A carboxylate and a carboxylic acid give different geometries.
  • Stereochemistry — define chiral centres in the SMILES with @ or @@; a flat input cannot invent stereochemistry.
  • Force field — MMFF94 is preferred for organic molecules; UFF covers elements that MMFF94 does not. Record which one was used if the geometry matters for a publication.
  • Single conformer — the tool returns one low-energy conformer, not an ensemble. Flexible molecules can have many accessible conformations; use a dedicated conformer generator if you need to sample them.
  • Molecule size — generation is fast for drug-like small molecules and slower for large, flexible structures. Proteins and nucleic acids are better handled by a dedicated molecular viewer.

3D structure vs 2D structure

A 2D structure encodes connectivity and bond orders on a flat canvas. It is ideal for communication and for databases, but it says nothing about the shape of the molecule. A 3D conformer adds coordinates, so you can inspect bond lengths, torsions, ring puckering and steric clashes. For docking or molecular dynamics, the 3D coordinates are the input; a 2D drawing is not enough.

Common uses

  • Preparing a ligand for docking or molecular dynamics (SMILES to SDF gives the same SDF output in a converter workflow).
  • Checking whether a proposed structure is geometrically reasonable.
  • Generating starting coordinates for a quantum-chemistry calculation (SMILES to XYZ).
  • Making figures for a report, poster or lecture.
  • Feeding a 3D structure into a browser-based viewer without installing software.

For large batches, use the batch converter with the “Generate 3D” option, or call the API from a script.

Frequently asked questions

Is the generated 3D structure accurate?

It is a force-field-optimised conformer, which is usually a reasonable low-energy geometry for a drug-like molecule. It is not an experimental structure and it is not guaranteed to be the global minimum. Treat it as a starting point and check it against experimental data when available.

Which force field does it use?

OpenBabel chooses MMFF94 when parameters are available and falls back to UFF otherwise. The exact force field is not exposed as a separate setting on this page.

Can I generate multiple conformers?

This page generates one conformer per request. For an ensemble, use a dedicated conformer search tool (for example RDKit's ETKDG or OpenBabel's conformer search) and optimise each conformer separately.

Does it work with proteins or DNA?

The tool is intended for small molecules. A protein or a long nucleic acid is usually too large for a single force-field optimisation in the browser; use a molecular viewer or a structure-preparation pipeline instead.

Can I download the coordinates?

Yes — use “Download SDF”. The file contains the 3D coordinates and can be opened in PyMOL, ChimeraX, Avogadro, Discovery Studio and most docking programs.

Why does generation sometimes take a few seconds?

The force-field optimisation is iterative. Small molecules finish quickly; larger or highly flexible molecules need more steps. The page shows a status message while the job runs.
