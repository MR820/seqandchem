What is SeqChem?

SeqChem wraps several open-source tools behind a simple web interface. OpenBabel — the chemistry toolbox used by researchers worldwide — handles every conversion, descriptor calculation and structure generation, so you get the same results as the command line without installing anything. OPSIN parses IUPAC names, with PubChem as a fallback for trivial names, and the sequence tools are implemented natively in Python.

Common workflows

  • SMILES → InChI / InChIKey — standardise structures for databases and patents.
  • SMILES → 3D SDF — generate a conformer for docking or visualisation.
  • SDF → SMILES — flatten a structure file into a one-line representation.
  • SMARTS substructure search — filter a compound list by functional group.
  • Tanimoto similarity — cluster or deduplicate a screening library.
