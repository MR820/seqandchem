IUPAC Name to Structure Generator

Type a systematic IUPAC name and get the chemical structure back — SMILES, InChI, InChIKey, molecular formula and a drawn structure image. Parsing is done by OPSIN, with PubChem as a fallback for common and trivial names.

Up to 20 names per run · lookups are not stored

What this IUPAC name generator does

Enter a systematic name such as 2-acetoxybenzoic acid and the tool returns the structure as a SMILES string, an InChI, an InChIKey, a molecular formula and a 2D drawing. You can process up to 20 names in one run. The result can be copied into the format converter, the 3D structure generator or the property calculator.

This is a name-to-structure tool, not a name-to-name translator. It does not generate an IUPAC name from a structure; for that, use a dedicated nomenclature tool and check the result carefully, because systematic names are not unique.

How it works

The name is first sent to OPSIN (Open Parser for Systematic IUPAC Nomenclature), a rule-based parser from the University of Cambridge that reads systematic nomenclature directly — no dictionary lookup. If OPSIN cannot interpret the name (common for trivial names such as “aspirin” or trade names such as “Tylenol”), the browser queries PubChem directly, which maintains a large curated name-to-structure index.

Keeping the two paths separate matters: OPSIN validates the grammar of the name, while PubChem resolves names that were never systematic. A name that looks systematic but is malformed will fail OPSIN; a trivial name will usually resolve through PubChem.

What OPSIN handles well

  • Substitutive names — 2-chloro-4-nitrobenzoic acid
  • Fused ring systems — quinoline, naphthalene
  • Stereochemistry — (2R)-2-hydroxypropanoic acid
  • Esters, amides, salts and hydrates
  • Multiplicative prefixes — di, tri, tetra…
  • Functional-class names — ethyl acetate, methylamine

Limitations

  • Trivial and trade names are not IUPAC names — OPSIN rejects them, so the PubChem fallback takes over. The result depends on PubChem's name index.
  • Badly formed names fail in both sources; check the spelling and locants.
  • Biochemical names (enzymes, proteins, polymers) have no single structure and cannot be resolved to one SMILES.
  • Ambiguous names can map to more than one structure. Check the returned formula and drawing against the name before using the result.
  • PubChem lookups run from your browser, so they require direct access to pubchem.ncbi.nlm.nih.gov.

Frequently asked questions

Why does “aspirin” work but “2-acetoxybenzoic acid” also work?

“Aspirin” is a trivial name — OPSIN rejects it, so PubChem resolves it by name lookup. “2-acetoxybenzoic acid” is systematic, so OPSIN parses it directly. Both paths return a structure, but only the systematic name is guaranteed to be interpretable without a dictionary.

Is the structure validated?

Both sources return a parsed structure; the depiction you see is rendered from that SMILES by OpenBabel, so if the SMILES is wrong the drawing will be wrong too. Always check the structure against the name.

Can I convert the result further?

Yes — copy the SMILES into the format converter, the 3D structure generator or the property calculator. To get an InChIKey for database lookup, use the SMILES to InChI tool.

Does it handle stereochemistry?

Yes, when the name specifies it — for example (2R)-2-hydroxypropanoic acid. The stereo layer is preserved in the returned SMILES and InChI. If the name does not specify stereochemistry, the result is the unspecified structure.

What happens when OPSIN cannot parse a name?

The tool falls back to PubChem for that name. If PubChem also has no match, the name is reported as unresolved. Try the systematic name, check the spelling, or search PubChem directly for the compound.

Can I resolve multiple names at once?

Yes — one name per line, up to 20 names per run. For a larger list, use the API or split the list into batches.
