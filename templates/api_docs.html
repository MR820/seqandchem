SeqChem API

A free JSON API over OpenBabel, OPSIN and a set of native sequence tools. Convert between 190+ chemical formats, compute descriptors, draw structures, resolve IUPAC names and process FASTA/FASTQ — no API key, no sign-up, CORS enabled.

https://seqandchem.com
None
JSON (UTF-8)
120 / min per client
8 MB · 64 MB batch
OpenAPI 3.0

Calls are free. Please do not hammer the service — it is a single small server, and heavy endpoints are serialised.

Quick start

Convert a SMILES string to InChI:

curl -s https://seqandchem.com/api/v1/convert \
  -H 'Content-Type: application/json' \
  -d '{"from":"smi","to":"inchi","data":"CC(=O)Oc1ccccc1C(=O)O"}'

Same call from Python:

import requests

r = requests.post("https://seqandchem.com/api/v1/convert", json={
    "from": "smi",
    "to": "inchi",
    "data": "CC(=O)Oc1ccccc1C(=O)O",
})
r.raise_for_status()
print(r.json()["result"])
# InChI=1S/C9H8O4/c1-6(10)13-8-5-3-2-4-7(8)9(11)12/h2-5H,1H3,(H,11,12)

And from the browser — CORS is enabled, so this works from any origin:

const res = await fetch("https://seqandchem.com/api/v1/properties", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({ from: "smi", data: "CC(=O)Oc1ccccc1C(=O)O" }),
});
const data = await res.json();
console.log(data.rows[0].props.MW);   // 180.159

Format identifiers

Every format is referred to by its OpenBabel id: smi, can, inchi, inchikey, mol, sdf, mol2, pdb, xyz, cml, smi, png, svg, pdf and roughly 180 more. Get the full list with GET /api/v1/formats — it also tells you which formats can be read and which can be written.

curl -s https://seqandchem.com/api/v1/formats | python3 -m json.tool | head -20

GET /api/v1/formats

Lists every format with a description and whether it can be read, written, or both.

QueryTypeDescription
dirstringOptional filter: read or write
 
{
  "ok": true,
  "items": [
    {"id": "smi", "desc": "SMILES format", "read": true, "write": true},
    {"id": "inchi", "desc": "InChI format", "read": true, "write": true}
  ]
}

GET /api/v1/example

Returns aspirin in the requested format. Useful to check what a format looks like before writing a parser.

QueryTypeDescription
formatstringFormat id, default smi
 
{"ok": true, "format": "mol", "data": " aspirin\n ..."}

POST /api/v1/convert

Converts one or more records between any two readable/writable formats. Text output comes back in result; binary output (PNG, PDF, STL) comes back base64-encoded in data_url.

FieldTypeDescription
datastringRequired. Molecule data in the source format
fromstringInput format id, default smi
tostringOutput format id, default mol
optsstring[]Optional OpenBabel flags: --gen3d, --canonical, --addhydrogens, --deletehydrogens, --unique, --separate
 
{
  "ok": true,
  "binary": false,
  "result": "InChI=1S/C9H8O4/c1-6(10)13-8-5-3-2-4-7(8)9(11)12/h2-5H,1H3,(H,11,12)",
  "mime": "text/plain",
  "is_image": false,
  "log": "1 molecule converted"
}

Requesting a 3D format (sdf, mol2, xyz, pdb) adds --gen3d automatically if you do not pass it.

POST /api/v1/depict

Renders a 2D depiction and returns the raw SVG markup in svg. The SVG is self-contained — embed it directly in a page.

FieldTypeDescription
datastringRequired. Molecules to draw
fromstringInput format id, default smi
 
{"ok": true, "svg": "<svg xmlns=\"http://www.w3.org/2000/svg\" ...></svg>"}

POST /api/v1/gen3d

Generates a force-field optimised 3D conformer and returns an SDF block. This is a heavy operation: it is serialised across the whole server, so under load you may get 429 with a retry hint.

FieldTypeDescription
datastringRequired. Molecules
fromstringInput format id, default smi
 
{"ok": true, "result": " aspirin\n     RDKit          3D\n..."}

POST /api/v1/substructure

Filters molecules by a SMARTS pattern and returns the matching ones.

FieldTypeDescription
datastringRequired. Molecules to search
smartsstringRequired. SMARTS pattern, max 500 chars
fromstringInput format id, default smi
 
{"ok": true, "count": 2, "matches": ["CC(=O)Oc1ccccc1C(=O)O", "CC(=O)Nc1ccc(O)cc1"]}

POST /api/v1/fingerprint

Returns the raw fingerprint bit string for each molecule.

FieldTypeDescription
datastringRequired. Molecules
fpstringFP2 (default), FP3, FP4, MACCS, ECFP2, ECFP4, ECFP6
fromstringInput format id, default smi
 
{"ok": true, "result": "00000000 00000000 00000001 ...", "words": 18}

POST /api/v1/similarity

Tanimoto coefficient between two molecules.

FieldTypeDescription
astringRequired. First molecule
bstringRequired. Second molecule
fpstringFP2 (default), FP3, FP4, MACCS
fromstringInput format id, default smi
 
{"ok": true, "tanimoto": 0.4815, "bits_a": 54, "bits_b": 52, "common": 25, "union": 81}

POST /api/v1/iupac

Parses an IUPAC name with OPSIN (Cambridge) and returns the structure identifiers.

FieldTypeDescription
namestringRequired. IUPAC name, max 300 chars
 
{
  "ok": true,
  "resolved": true,
  "source": "opsin",
  "smiles": "CC(=O)Oc1ccccc1C(=O)O",
  "inchi": "InChI=1S/C9H8O4/c1-6(10)...",
  "inchikey": "BSYNRYMUTXBXSQ-UHFFFAOYSA-N"
}

If the name cannot be interpreted you get ok: true, resolved: false with a message — this is not an error, just a miss.

POST /api/v1/batch

Bulk conversion of a whole file. Returns result for text formats; for image formats it returns a per-molecule preview list and, when there is more than one record, a ZIP as a zip_url data URL. Limits: 64 MB input, 5,000 records per run (500 for image output).

FieldTypeDescription
datastringRequired. Multi-record file
fromstringInput format id, default sdf
tostringOutput format id, default smi
optsstring[]--canonical, --unique, --deletehydrogens, --addhydrogens
 
{"ok": true, "binary": false, "result": "CC(=O)Oc1ccccc1C(=O)O\n...", "converted": 250}

POST /api/v1/formula

Two modes: parse a formula string, or compute formula and weight from a structure.

FieldTypeDescription
modestringformula (default) or structure
formulastringUsed when mode is formula, e.g. C9H8O4
datastringUsed when mode is structure
fromstringInput format id for structure mode
 
{"ok": true, "formula": "C9H8O4", "mw": 180.159,
 "composition": {"C": 9, "H": 8, "O": 4}, "atoms": 21}

POST /api/v1/bio

Sequence operations, all implemented natively in Python.

FieldTypeDescription
opstringRequired. fasta2fastq, fastq2fasta, revcomp, translate, stats
datastringRequired. FASTA, FASTQ or a bare sequence
frameintegerReading frame for translate, 0–2
 
{"ok": true, "result": "ATGGCC...", "count": 3}

Errors

Failures always return the same shape, with an HTTP status of 400, 422 or 429:

{"ok": false, "error": "Conversion failed", "detail": "1 molecule converted"}
StatusMeaning
400Bad request — missing field, unknown format, input too large
422OpenBabel or OPSIN could not process the input
429Rate limit or a heavy job already running; see Retry-After
502Upstream name-resolution service unavailable

Limits and fair use

  • 120 requests per minute per client, 300 per minute across the whole service.
  • 8 MB maximum input per request; 64 MB for /api/v1/batch.
  • 5,000 records per batch run, or 500 when the output is an image (PNG, SVG, PDF…). Requests over the limit return 400 with the actual count and the maximum.
  • 3D conformer generation is serialised — one at a time across all users. Plan for a few seconds per molecule.
  • If you need sustained bulk throughput, generate 3D conformers locally with OpenBabel or RDKit; this API is meant for interactive and small-batch use.
