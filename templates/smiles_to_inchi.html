What is InChI?

InChI (International Chemical Identifier) is a standard, non-proprietary text identifier for chemical substances maintained by IUPAC. Unlike SMILES, which can be written in many equivalent ways for the same molecule, InChI is canonical: every valid representation of the same structure produces the same InChI string.

An InChI is built from layers: formula, connectivity, hydrogen, charge, stereochemistry and isotopes. A full InChI can be long, which is why the fixed-length InChIKey exists; use SMILES to InChIKey if you need the 27-character hash directly.

Why convert SMILES to InChI?

  • Deduplication — two different SMILES for the same molecule give one InChI.
  • Database lookup — PubChem, ChEMBL and Wikidata index compounds by InChI and InChIKey.
  • Regulatory and patent filing — InChI is the IUPAC standard for structure registration.
  • Stable keys — the 27-character InChIKey is a fixed-length hash you can use as a primary key.

What is preserved and what is not

InformationIn the InChI?
Connectivity and bond ordersYes
Formal chargesYes
Defined stereochemistryYes, in the stereo layer
IsotopesYes, in the isotopic layer
CoordinatesNo — SMILES has no coordinates and InChI does not store them
Comments or propertiesNo

Worked example

Aspirin, CC(=O)Oc1ccccc1C(=O)O, converts to InChI=1S/C9H8O4/c1-6(10)13-8-5-3-2-4-7(8)9(11)12/h2-5H,1H3,(H,11,12). A different SMILES for the same molecule produces the same InChI. The InChIKey for this structure is BSYNRYMUTXBXSQ-UHFFFAOYSA-N.

Salts, charges and tautomers

A salt appears as multiple components in the InChI. If you want the parent compound only, remove the counter-ion from the SMILES first. Formal charges are encoded in the charge layer. Standard InChI normalises mobile hydrogens, so some tautomers map to the same identifier; if tautomer identity matters, check the result and consider a non-standard InChI or an explicit tautomer workflow.

Frequently asked questions

Does it preserve stereochemistry?

Yes. OpenBabel reads stereo information from the SMILES (@ and @@ markers) and encodes it in the InChI layer, so chiral centres are preserved.

Will I get the InChIKey too?

The output is InChI. To get the InChIKey, use SMILES to InChIKey or the property calculator.

Are coordinates preserved?

No. SMILES does not contain coordinates, and InChI does not store them. Use an SDF or MOL file if you need a specific geometry.

Why is the InChI so long?

The string encodes several layers (formula, connectivity, hydrogens, charge, stereo, isotopes). Large or highly connected molecules produce longer strings. Use the InChIKey when you need a fixed-length identifier.

Can I convert the InChI back to SMILES?

Yes — use InChI to SMILES. The round trip preserves connectivity and defined stereochemistry; the exact SMILES string may differ.

Does it handle salts?

Yes — the salt appears as multiple components. Remove the counter-ion first if you want the parent compound only.
