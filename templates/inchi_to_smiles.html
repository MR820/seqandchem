What this InChI to SMILES converter does

InChI is great for storing and comparing structures, but many toolkits, machine-learning pipelines and cheminformatics scripts expect SMILES. This page converts an InChI string into a standard SMILES representation using OpenBabel.

Paste one or more InChI strings, one per line. The output is a SMILES string for each structure, in the same order. To go the other way, use SMILES to InChI; for a fixed-length key, use InChI to InChIKey.

When do you need this?

  • You downloaded a compound list from PubChem and need SMILES for a model.
  • Your database stores InChI but your viewer or editor only accepts SMILES.
  • You want to inspect or edit the structure in a drawing tool.
  • You need a compact string for a script or a machine-learning pipeline.

What is preserved

  • Connectivity — the atom and bond graph encoded in the InChI.
  • Formal charges — the charge layer.
  • Stereochemistry — the stereo layer, including tetrahedral and double-bond geometry when specified.
  • Isotopes — the isotopic layer, when present.

Coordinates are not part of InChI, so the SMILES cannot carry a specific geometry. If you need coordinates, convert the InChI to MOL or SDF and generate a layout or conformer.

Notes on the result

InChI encodes connectivity, tautomers and stereochemistry together. When converting back to SMILES, the result is one valid representation — it may differ textually from the original SMILES but describes the same molecule. SMILES is not unique, so do not compare strings for identity; compare InChI, InChIKey or the structure itself.

Standard InChI normalises mobile hydrogens, so a tautomer may come back as a different tautomeric form than the one you started with. Check the structure if tautomer identity matters.

Worked example

Aspirin is InChI=1S/C9H8O4/c1-6(10)13-8-5-3-2-4-7(8)9(11)12/h2-5H,1H3,(H,11,12). Converting it to SMILES gives a valid representation of aspirin, such as CC(=O)Oc1ccccc1C(=O)O. The string may differ from the one in a database, but the connectivity and stereochemistry are the same.

Frequently asked questions

Can I convert an InChIKey to SMILES?

No. InChIKey is a one-way hash — you cannot recover the structure from it. You need the full InChI string or the structure itself.

Why is the SMILES different from the original?

SMILES is not unique; the same molecule can be written in many valid ways. The converter may produce a different valid SMILES. Compare connectivity and stereochemistry, not string equality.

Are coordinates preserved?

No. InChI does not store coordinates. Use InChI to MOL and generate a 2D layout or a 3D conformer if you need geometry.

Does it preserve stereochemistry?

Yes, when the InChI has a stereo layer. The SMILES carries the stereo information as @/@@ markers and directional bonds.

What about salts and mixtures?

A multi-component InChI produces a SMILES with dot-separated components. If you want the parent compound only, remove the counter-ion first.

Can I convert multiple InChIs at once?

Yes — paste one InChI per line. The output contains one SMILES per structure in the same order.
