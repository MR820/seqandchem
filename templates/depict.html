2D Structure Generator

Draw a clean 2D skeletal structure from a SMILES, InChI or any supported chemical format. The result is a vector SVG you can download and use anywhere.

What this 2D structure generator does

Paste a SMILES string, InChI, MOL, SDF, PDB or another supported structure and the tool draws a clean 2D skeletal structure. OpenBabel lays the molecule out on a plane using a ring-aware algorithm, so fused rings, side chains and substituents are placed in a readable orientation. The result is a vector SVG you can download and use in a paper, slide, patent or web page.

The drawing is a 2D depiction, not a 3D conformer. If you need geometry, use the 3D structure generator; if you need a raster image, use SMILES to PNG.

How the layout works

The converter first perceives bonds and aromaticity from the input, then assigns 2D coordinates. The layout tries to keep bond lengths uniform, avoid atom overlaps and draw rings as regular polygons. For most drug-like molecules the result is publication-ready without manual adjustment.

Automatic layout is a heuristic. Crowded structures, macrocycles, overlapping side chains and unusual ring systems may need a structure editor for a final clean-up. Use this tool for a quick figure or a sanity check, and a dedicated editor for a camera-ready drawing.

What the image shows

  • Atom labels — heteroatoms and charged groups are labelled; carbons are usually unlabelled.
  • Bonds — single, double, triple and aromatic/Kekulé representations.
  • Stereochemistry — wedge and hash bonds when the input defines chiral centres or double-bond geometry.
  • Charges — formal charges shown next to the atom.
  • Hydrogens — implicit hydrogens are not drawn unless needed for stereo or a charged group.

SVG vs PNG

FormatBest forTrade-off
SVGPapers, posters, patents, scalable web figuresVector; some old tools do not import it
PNGSlides, chat, quick documentsFixed 300 × 300 pixels; white background

Use SVG when the figure will be printed or scaled. Use SMILES to PNG when you need a simple raster image.

Common uses

  • Turning a SMILES from a database into a figure for a report.
  • Checking that a SMILES string matches the intended structure.
  • Producing structure images for a website or a patent filing.
  • Illustrating a reaction scheme or comparing analogues.
  • Creating a clean structure for a slide or a lecture.

What to check

  • Aromatic rings — confirm the Kekulé/aromatic representation matches the intended structure.
  • Charges — a missing or extra formal charge changes the molecule; check the label.
  • Stereochemistry — if the source has no stereo information, the drawing cannot invent it.
  • Salts — counter-ions appear as separate fragments; strip them if you want the parent compound only.

For a machine-readable structure, use SMILES to InChI or the format converter. For molecular properties, use the property calculator.

Frequently asked questions

Is the drawing a 3D structure?

No. It is a 2D depiction with a flat layout. Use the 3D structure generator for a conformer with coordinates.

Can I download the image?

Yes — use “Download SVG”. The file is a vector image and can be opened in a browser, Illustrator, Inkscape or a document editor.

Does it preserve stereochemistry?

Yes, when the input defines it. Chiral centres and double-bond geometry are drawn with wedge, hash or directional bonds. A flat input without stereo information cannot produce a stereo-defined drawing.

Why does my molecule look crowded?

Automatic layout is a heuristic. Large or highly branched molecules can overlap; use a structure editor for a final manual adjustment.

Can I draw multiple molecules at once?

This page depicts one structure per run. For a library, use the batch converter with an image output format, which packs one image per molecule into a ZIP file.

SVG or PNG — which should I use?

Use SVG for papers, posters and anything that will be scaled. Use PNG for slides, chat and quick documents.
