2D Structure Generator

Draw a clean 2D skeletal structure from a SMILES, InChI or any supported chemical format. The result is a vector SVG you can download and use anywhere.

About 2D depiction

OpenBabel lays the molecule out on a plane using a ring-aware layout algorithm, so fused rings and side chains are drawn in a readable orientation. The output is vector SVG — infinitely scalable, ideal for papers, slides, patents and web pages.

Typical use cases

  • Turn a SMILES string from a database into a figure for a report
  • Verify that a SMILES string matches the intended structure
  • Produce structure images for a website or patent filing
