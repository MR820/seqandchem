What is a reverse complement?

DNA is double-stranded, and the two strands run in opposite directions. Each strand is the reverse complement of the other. Given 5′-ATGGC-3′ on one strand, the opposite strand reads 5′-GCCAT-3′ when written in the conventional 5′→3′ direction.

The operation has two steps:

  1. Complement every base: A↔T and G↔C.
  2. Reverse the resulting string, because the two strands are antiparallel.

For ATGGC, the complement is TACCG and the reverse complement is GCCAT. If you only complement or only reverse the sequence, you get a string that does not represent the opposite strand.

Reverse complement vs reverse vs complement

OperationInput 5′-ATGGC-3′OutputUse
ComplementATGGCTACCGOpposite bases, same order
ReverseATGGCCGGTASame bases, opposite order
Reverse complementATGGCGCCATThe opposite strand, 5′→3′

Lowercase and masked bases are complemented and reversed in the same way. U is accepted for RNA and complemented to A; A is still complemented to T. Spaces and line breaks inside a sequence are ignored. Any character outside the IUPAC codes (for example digits or gap characters) is rejected with an error. A bare sequence is one record and comes back on a single line; FASTA records are converted separately.

Why the 5′→3′ direction matters

Sequences are written 5′→3′ by convention. When you copy a sequence from a paper, a primer order form or a genome browser, confirm the direction before using it. A reverse complement is not a cosmetic transformation: it is the sequence of the other strand, and it is what a polymerase reads when it extends a primer on the opposite strand.

This matters for primer design. If the forward primer is 5′-ATGCGT-3′, the reverse primer is designed from the reverse complement of the target's 3′ end: 5′-ACGCAT-3′. Getting the orientation wrong is a common reason a PCR reaction produces no product.

Common uses

  • Designing and checking reverse PCR primers.
  • Determining whether a sequencing read maps to the forward or reverse strand.
  • Analysing genes on the minus strand of a genome.
  • Converting a coding sequence to the strand a ribosome reads, before translation.
  • Preparing insert sequences for cloning when the orientation is fixed by the vector.

Batch and FASTA input

The calculator accepts a bare sequence or a multi-record FASTA file. For each record, the header is kept and only the sequence is reverse-complemented. That makes it possible to process a primer list or a set of gene sequences in one paste. For sequence statistics after the conversion, use the GC content calculator; for FASTA/FASTQ format conversion, see the FASTA vs FASTQ guide.

Reverse complement in Python

Biopython provides the operation directly:

from Bio.Seq import Seq

seq = Seq("ATGGC")
print(seq.reverse_complement())   # GCCAT

Without Biopython, the standard library is enough:

seq = "ATGGC"
table = str.maketrans("ACGTacgt", "TGCAtgca")
reverse_complement = seq.translate(table)[::-1]
print(reverse_complement)          # GCCAT

The web tool uses the same logic, with additional IUPAC ambiguity codes and FASTA parsing.

Frequently asked questions

Is reverse complement the same as reverse?

No. Reverse only changes the order of the bases. Reverse complement changes the order and replaces each base with its partner (A↔T, G↔C), which is what the opposite DNA strand contains.

How do I reverse complement a primer?

Paste the primer sequence in the 5′→3′ direction and run the tool. The output is the reverse complement, also written 5′→3′. For a primer order, enter the sequence exactly as you want it synthesized; the synthesizer reads it 5′→3′.

Does it work with RNA?

The tool accepts U in the input and complements it to A. The output strand uses T for DNA; if you need an RNA string, replace T with U in the result and check that your downstream tool expects RNA.

What happens to lowercase or masked bases?

Lowercase bases are complemented to lowercase and reversed with the rest of the sequence. Masked regions therefore stay masked in the output.

Can I process multiple sequences at once?

Yes. Paste a multi-record FASTA file; each record is processed independently and the headers are preserved. For a large file, use the API with the revcomp operation.
