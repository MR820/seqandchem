What this SMILES to PNG converter does

Turn a SMILES string into a raster structure image you can drop into a slide, a report, a document or a database record. OpenBabel lays out the 2D coordinates and renders the molecule as a 300 × 300 PNG with a white background.

The image shows the 2D depiction: atom labels, bonds, ring systems, formal charges and stereochemistry where the SMILES defines it. It is a picture, not a structure file — if you need coordinates or a machine-readable format, use SMILES to MOL or SMILES to SDF.

PNG or SVG?

  • PNG — fixed resolution, universally supported, ideal for slides, chat and quick documents.
  • SVG — vector, infinitely scalable, ideal for papers, posters and print. Use the 2D structure generator for SVG output.

For a figure that will be printed at large size, use SVG. For a figure that will be pasted into a slide or a chat message, PNG is usually more convenient.

How to get a better image

  • Use a clean SMILES — remove salts and counter-ions if you only want the parent compound.
  • Define stereochemistry — a SMILES with @ or @@ produces a depiction with wedge/hash bonds.
  • Choose the right tool — for a scalable figure, use the SVG depiction tool; for a 3D view, use SMILES to 3D.
  • Check the layout — automatic 2D layout is usually good for drug-like molecules, but crowded or unusual structures may need manual adjustment in a structure editor.

What the image contains

  • Atom labels — element symbols; carbons are usually unlabelled.
  • Bonds — single, double, triple and aromatic/Kekulé representations.
  • Charges — formal charges shown next to the atom.
  • Stereochemistry — wedge and hash bonds for defined chiral centres.

Hydrogens are implicit by default and are not drawn unless they are needed to show stereochemistry or a charged group.

Common uses

  • Adding a structure to a slide, poster or report.
  • Creating a thumbnail for a compound database or catalogue.
  • Illustrating a reaction scheme or a comparison of analogues.
  • Sharing a molecule in a chat or issue tracker without sending a structure file.

Limitations

  • Fixed size — the output is 300 × 300 pixels. For a larger raster, render at higher resolution with a local OpenBabel install or use SVG.
  • White background — the PNG is not transparent. Use SVG if you need a transparent background.
  • No atom numbering or custom colours — the depiction is clean and standard; use a structure editor for publication-specific styling.
  • 2D only — the image is a 2D layout, not a 3D conformer.

Frequently asked questions

Why is the image small?

The default canvas is 300 × 300 pixels. For a larger figure, use the SVG output and scale it, or render at higher resolution with a local OpenBabel install.

Can I get a transparent background?

The PNG output has a white background. SVG output keeps a transparent background.

Can I change the image size?

This page uses a fixed 300 × 300 canvas. For a different size, use the SVG depiction tool and set the dimensions in your document, or run OpenBabel locally with your preferred options.

Does it show stereochemistry?

Yes, when the SMILES defines it with @ or @@. The depiction uses wedge and hash bonds for defined chiral centres.

Does it show hydrogens?

Hydrogens are implicit and are not drawn by default. They may appear when needed to show stereochemistry or a charged group.

PNG or SVG — which should I use?

Use PNG for slides, chat and quick documents. Use SVG for papers, posters and anything that will be printed or scaled. The 2D structure generator produces SVG.
