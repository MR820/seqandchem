SMARTS Substructure Search

Paste a list of molecules and a SMARTS pattern. Every structure containing the pattern is returned — ideal for filtering screening libraries by functional group.

What this SMARTS substructure search does

Paste a list of molecules and a SMARTS pattern. The tool converts each molecule to a structure, tests whether the pattern can be mapped onto it, and returns every matching molecule. It is the fastest way to filter a screening library by functional group, ring system or atom environment without writing a script.

Inputs can be SMILES, MOL, SDF, PDB, InChI and other readable formats. For a single molecule, the Tanimoto similarity calculator answers a different question: how similar two structures are, rather than whether a specific pattern is present.

SMILES vs SMARTS

SMILES describes one specific molecule. SMARTS describes a query: atom properties, bond types, charge, ring membership and connectivity can all be constrained. Substructure matching returns a molecule if the pattern can be mapped onto any part of it.

For example, c1ccccc1 matches a benzene ring, while [#6]=[#6] matches any carbon–carbon double bond. A SMARTS pattern can be as broad or as specific as the question requires.

SMARTS syntax essentials

SyntaxMeaning
c, CAromatic carbon / aliphatic carbon
[C], [N], [O]Any carbon, nitrogen or oxygen atom with the bracket properties
=, #, :Double, triple or aromatic bond
~Any bond
*Any atom
[R], [R2]Atom in a ring / in two rings
[+1], [-1]Formal charge
; , , , &Logical AND, OR, AND (low precedence)
!$(...)Recursive SMARTS exclusion

Common SMARTS patterns

  • c1ccccc1 — benzene ring
  • [CX3](=O)[OX2H1] — carboxylic acid
  • [NX3;H2,H1;!$(NC=O)] — primary or secondary amine, excluding amides
  • [OX2H] — hydroxyl group
  • [#6]=[#6] — carbon–carbon double bond
  • [F,Cl,Br,I] — any halogen
  • [R] — any atom in a ring

How matching works

The matcher looks for a subgraph isomorphism: every atom and bond in the pattern must map to a distinct atom and bond in the molecule, respecting the atom and bond constraints. Aromatic atoms, charges, isotopes and ring membership are part of the match. The result is binary — a molecule either matches or it does not — so the output is a filtered list, not a ranked score. A pattern that OpenBabel cannot parse is an error, not a search with zero hits; an empty result means the pattern is valid and none of the molecules contain it.

Workflow

  1. Choose the input format and paste the molecules, one per line or as an SDF.
  2. Enter a SMARTS pattern, or start from one of the examples above.
  3. Run the match and copy or download the filtered list.
  4. For a library, use the batch converter or the API.

Limitations

  • Aromaticity perception — aromatic and Kekulé forms must be perceived consistently; an unusual tautomer may not match the expected pattern.
  • Explicit vs implicit hydrogens — a pattern that depends on an explicit hydrogen may not match a molecule with implicit hydrogens.
  • Performance — complex recursive SMARTS on a large library is slower than a simple atom/bond query.
  • Not a 3D pharmacophore search — matching uses the 2D connection table, not conformation or spatial arrangement.

Frequently asked questions

What is the difference between SMILES and SMARTS?

SMILES describes one molecule; SMARTS describes a query. A SMARTS pattern can include wildcards, atom properties, charge, ring membership and logical operators, so it matches a family of structures rather than one exact molecule.

Why does my pattern not match a molecule that looks right?

Check aromaticity, explicit hydrogens and charge. A pattern written for a Kekulé structure may not match an aromatic representation, and a pattern that requires an explicit hydrogen will not match implicit hydrogens.

Can I search multiple patterns at once?

This page runs one pattern per query. For multiple patterns, run the search again or use a script with the API.

Does it return the matching substructure?

The page returns the molecules that match. Use a structure editor or a dedicated substructure highlighter if you need the matched atoms highlighted.

Can I search an SDF library?

Yes — paste the SDF or upload it. Each record is tested independently, and the output keeps the molecules that match.

Is the match case-sensitive?

Yes in the SMARTS sense: c is aromatic carbon and C is aliphatic carbon. Use the correct case for the atom type you mean.
