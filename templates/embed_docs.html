Notes

  • The widget is a plain <iframe> — it works in WordPress, Ghost, Hugo, Notion embeds, Jekyll, plain HTML, anywhere that allows raw HTML.
  • Conversion runs on our server through the same API the site uses. Conversion data is not stored.
  • Please keep the small “Powered by SeqChem” link — it is the only thing we ask in return. Removing it will not break the widget.
  • If you want a different size, format pair or theme, send anonymous feedback and we will consider adding a preset.

What the widget includes

The iframe contains a small, self-contained converter: an input box, an output-format picker and a Convert button. It uses the same public API as the rest of SeqChem, so it supports SMILES, InChI, InChIKey, MOL, SDF, MOL2, PDB, XYZ, CML, SVG and PNG output. The widget does not set cookies, does not require an API key and does not track individual readers.

CSP and iframe embedding

If your site sends a Content-Security-Policy with a frame-src directive, add https://seqandchem.com to that directive. The widget response allows embedding from HTTP and HTTPS pages; the main SeqChem pages themselves use X-Frame-Options: SAMEORIGIN. If a browser shows a blank box, check the browser console first — it usually names the blocked frame or a mixed-content problem.

Troubleshooting

  • Blank iframe: allow seqandchem.com in the embedding page's CSP, and load the parent page over HTTPS.
  • Too small: use a minimum height of 330 px for a one-line converter, or 380–420 px when the format picker and result panel are both visible.
  • No output for a valid molecule: try the full format converter and check the input format selector; a PDB or MOL2 file may need different input handling than a SMILES string.
  • Rate-limited: the public API allows 120 requests per minute per client; interactive use is far below that, but a page that calls it in a loop may hit the limit.

Frequently asked questions

Can I use the widget on a commercial site?

Yes. The converter is free to embed; keeping the attribution link is appreciated but not a technical requirement.

Does the widget work without JavaScript?

No. The conversion runs through a small JavaScript fetch call, so JavaScript must be enabled in the embedding page.

Can I change the title or default formats?

Yes. Use the title, from and to query parameters shown above; the values are reflected in the iframe heading and initial selectors.
