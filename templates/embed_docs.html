Drop a working chemical format converter into any page with one line of HTML. Free, no API key, no account, no tracking of your readers.

A SMILES → InChI converter, 330 px tall:

<iframe src="https://seqandchem.com/embed/convert?from=smi&to=inchi"
        style="width:100%;height:330px;border:1px solid #e5e7eb;border-radius:10px"
        title="SMILES to InChI converter"></iframe>

A SMILES → MOL converter, with a format picker:

<iframe src="https://seqandchem.com/embed/convert?from=smi&to=mol"
        style="width:100%;height:360px;border:1px solid #e5e7eb;border-radius:10px"
        title="SMILES to MOL converter"></iframe>

Options

ParameterDefaultMeaning
fromsmiInput format id — smi, inchi, mol, sdf, pdb, xyz, cml, mol2
tomolPreselected output format
titleautoHeading shown in the widget

Output formats available in the picker: SMILES (canonical), InChI, InChIKey, MOL, SDF, MOL2, PDB, XYZ, CML, SVG and PNG.

Notes

  • The widget is a plain <iframe> — it works in WordPress, Ghost, Hugo, Notion embeds, Jekyll, plain HTML, anywhere that allows raw HTML.
  • Conversion runs on our server through the same API the site uses. Nothing is stored.
  • Please keep the small “Powered by SeqChem” link — it is the only thing we ask in return. Removing it will not break the widget.
  • If you want a different size, format pair or theme, email devin2xing@gmail.com and we will add a preset.
