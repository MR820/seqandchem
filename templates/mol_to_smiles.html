MOL to SMILES converter

A MOL file is a single-molecule structure file in the MDL format — the same record format used inside SDF files, just without the property block and without the record separator. This converter turns one MOL file into a SMILES string.

Common use cases

  • You drew a structure in ChemDraw, Marvin or Avogadro and need the SMILES.
  • You have a MOL file from a vendor catalogue and want to search it in a database.
  • You are building a dataset and need a uniform text representation.

Frequently asked questions

MOL vs SDF — what is the difference?

SDF is essentially a MOL file followed by data fields and a $$$$ separator, so one SDF file can hold many molecules while a MOL file holds exactly one. If your file has multiple records, use SDF to SMILES instead.
